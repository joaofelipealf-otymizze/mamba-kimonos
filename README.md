# Mamba Kimonos

Site estático (HTML, CSS e JS). Publicado em https://mambakimonos.otymizze.com.br

## Trocar as fotos

Envie as fotos reais para a pasta `assets/` com estes nomes exatos (.jpg, ~1200 px de largura):

- `foto-branco.jpg`, `foto-preto.jpg`, `foto-azul.jpg`: cada kimono, na vertical
- `foto-producao.jpg`: bancada, corte ou costura (horizontal)

O site troca sozinho. Quando as 3 fotos dos kimonos existirem, o aviso "imagens ilustrativas" some.
